# Smart Home Control App -> SyntaxHome

<img src=SmartHome/Images/screenshot.png width=75%>


This SwiftUI app simulates a simple smart home control system. It allows users to:

- **Control Lights**: Turn one or more lights on or off with visual feedback using SF Symbols.
- **Adjust Temperature**: Set the desired temperature using a slider, with the current value displayed.
- **Control Doors**: Open and close a door using a toggle button, with optional animation or icon change.

## Features

- ✅ Toggle switches for lights and doors  
- ✅ Visual feedback through SF Symbols (color or icon changes)  
- ✅ Adjustable temperature with live display  
- ✅ Clean and responsive layout using VStack, HStack, and ZStack  
- ✅ State management with `@State` and `@Binding`  

## Technologies

- SwiftUI  
- SF Symbols  
- Swift `@State` / `@Binding`  
- Layout stacks (VStack, HStack, ZStack)

## How to Run

1. Click the green **"Code"** button on this repository and select **"Open with Xcode"** (if available), or download the ZIP and open the project manually.
2. Alternatively, open the `.xcodeproj` or `.xcodeworkspace` file directly in **Xcode**.
3. Click the **Run** ▶️ button in the top toolbar to build and launch the app in the iOS Simulator or on a physical device.
4. Interact with the smart home UI to test light, temperature, and door controls.
