# The app should offer the following functions:

## Control lights

- Switching one or more lights on/off
- Visual feedback (e.g. symbol color, icon change)

## Control temperature

- Adjustable temperature value (slider, stepper or buttons)
- Display of the current temperature

## Door control

- Opening and closing via switch or button
- Optional: animation or symbol change


# Technical Components:

## SwiftUI components

- Toggle or button (for light & door)
- Slider, stepper or picker (for temperature)
- @State / @Binding variables for status management
- VStack, HStack, ZStack for arrangement in the layout
- Icons (e.g. from SF Symbols) for visual feedback
